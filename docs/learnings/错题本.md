# 错题本

## 2026-08-02: UI 重写导致 CaptiOCR 选择器功能退化

### 现象
重写 DanmakuPanel UI 后，"📐 选择截图区域"按钮点击无反应，CaptiOCR 全屏选择窗口不弹出。用户发现后反馈。

### 根因
1. **UI 改坏了功能绑定**：重写 JSX 时，选择了"📐 选择区域"按钮的事件绑定使用 `api.openRegionSelector()` 调用后端 API，但 `openRegionSelector` 方法存在拼写错误或不匹配，导致 API 调用失败。
2. **没有验证核心流程**：改代码后只验证了 UI 渲染正确（按钮出现、颜色对），没有手动点击按钮测试 E2E 流程。
3. **Moat 无覆盖**：Textream 项目只有静态分析 Moat，没有集成测试，无法拦截功能退化。

### 教训
- **UI 改动后必须手动测试 3 个核心功能流**：
  1. 点击"选择区域" → CaptiOCR 窗口出现
  2. 拖拽选择 → 坐标返回
  3. 点击"开始捕获" → 弹幕开始流入
- **重写组件时保留原始功能逻辑**，只改样式和布局
- **功能按钮的事件绑定必须验证**：检查 `onClick` 对应的函数名和 `api` 方法名是否一致
